CONTEXTO DO JOGO

Uma conclusão envolve
vários componentes

Ao terminar uma atividade,
o jogo precisa:

  1. Adicionar XP ao pet.
  2. Verificar sua evolução.
  3. Registrar no histórico.
  4. Avaliar conquistas.
SE CADA TELA COORDENAR TUDO

Ela precisa conhecer os componentes e repetir a sequência.

Uma mudança no fluxo pode exigir alterações em vários clientes.

Contexto: classes e fluxos da Entrega 02. O exemplo parte de uma atividade já concluída.

COORDENAÇÃO DA OPERAÇÃO

O caminho de uma conclusão

Atividade concluída · categoria e XP calculados e validados

  1. Validar dados e consultar o histórico
  2. Adicionar XP ao pet
  3. Verificar evolução
  4. Registrar a conclusão
  5. Avaliar e desbloquear conquistas
  6. Retornar o resultado ao cliente

Fluxo ilustrativo. A execução real será mostrada no Python.

Se o identificador já existe no histórico, retornar JA_REGISTRADA sem repetir os efeitos.

MODELAGEM DINÂMICA

A ordem das chamadas

Primeiro consultar; depois alterar o estado. O histórico é atualizado antes da avaliação das conquistas.

IMPLEMENTAÇÃO EM PYTHON

A coordenação em um método

if self.historico.possuiConclusao(idConclusao):
    return ResultadoConclusao(
        SituacaoConclusao.JA_REGISTRADA)

self.pet.adicionarXP(categoria, pontos)
self.pet.verificarEvolucao()
self.historico.registrarConclusao(
    idConclusao, categoria, pontos)

for conquista in self.conquistas:
    if (not conquista.foiDesbloqueada
            and conquista.validarRequisitoGeral(self.usuario)):
        conquista.desbloquearConquista()
        novas.append(conquista.nome)

Delegação

O pet decide a evolução.

O histórico guarda a ocorrência.

A conquista avalia seu critério.

A fachada conhece a sequência.

Trecho de concluirAtividade(). Validação de entrada, montagem e retorno serão mostrados no arquivo completo.
