## Visualizar a documentação localmente

Com Node.js instalado, execute na raiz do repositório:

```powershell
node serve-docs.cjs
```

Abra [http://localhost:8000](http://localhost:8000) no navegador. Para encerrar o servidor, pressione `Ctrl+C` no terminal. O site usa Docsify e lê diretamente os arquivos Markdown de `docs/`; não há etapa de build.
